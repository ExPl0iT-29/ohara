Support

Help with Ohara for Android.

Contact

The fastest way to get help or report a bug is to open an issue on GitHub. Include your Android version, the link you tried to save (if it's about a specific page) and what happened. You can also use the developer contact address on Ohara's Google Play listing.

A link didn't save properly

Some sites only show their text after running scripts, block automated requests, or sit behind a login. Ohara then keeps what it can (title, description and image) and offers Open original link. If an item says it couldn't be processed, open it and tap Retry.

Ohara doesn't appear in the share menu

Open Ohara once after installing it, then try sharing again. In some apps the share menu lists recent targets first; scroll or tap More to find Ohara.

Backing up or moving to a new phone

Go to Settings → Export library and save the file somewhere safe (for example Google Drive or email it to yourself). On the new phone, install Ohara and use Settings → Import from file. Everything comes across: articles, tags, highlights and reading positions.

Importing links from another app

Ohara imports a JSON file shaped like [{"url": "https://…"}, …]. Each link is saved and prepared as if you had shared it.

Deleting your data

Ohara has no account and the developer has no copy of your library. To delete everything, clear Ohara's storage in Android Settings, or uninstall the app.
